# 來源、查閱範圍與限制

[回到首頁](../README.md) · [證據清單](../evidence/evidence-register.csv) · [參考來源](references.md)

## 三類材料

1. **歷史原稿 S01：**使用者提供的 31 頁團隊簡報。支持團隊當時的產品、流程與知識分類描述，不足以單獨證實企業現況、技術效能或營運績效。
2. **公司第一方資料 W01–W06：**2026-10-28 查閱的公司官網。用於檢查公開服務定位；網站內容與公司主張不等於獨立驗證，亦不回填為課程當時的事實。
3. **外部概念資料 X01–X02、T01–T02：**FDA、NSGC 與 Kano／IPA 原始出版者資料，用於界定概念與研究設計，不是對先見基因的產品認可。

本次新增的機制、商業模式、競爭分析與策略建議屬 **A 類分析**。證據清單明列其依據與限制。

## 官網補充與歷史材料分開

| 官網觀察 | 支持的最小結論 | 不支持的延伸結論 |
| --- | --- | --- |
| 關於頁敘述跨專業團隊與發展歷程 | 公司公開強調專業整合 | 已驗證組織結構或創新績效 |
| 介紹頁呈現線上訂購與居家採樣 | 存在面向使用者的採樣通路說明 | 所有產品都屬純 DTC，或已完成實際訂購測試 |
| 商品頁對部分風險評估標示非臨床用途 | 需逐項閱讀產品用途 | 所有項目的醫療資格或效果都相同 |
| 基因銀行頁有長期服務、保存期間與年費說明 | 有具體方案文字可追問期間與收費關係 | 已取得完整條款、已實現收入或已證實續約率 |
| 隱私政策敘述資料使用與第三方原則 | 有公開政策可閱讀 | 已稽核後端權限、刪除作業或資安控制 |

各項連結見 [參考來源](references.md)。首頁認證說明指向特定檢測項目；本案沒有查驗認證機構即時名錄、證書效期與完整範圍，因此不以此背書全部產品。

## 原稿完整保留與公開邊界

原始 PDF 在本機 `.private/genomics/source/` 留存，SHA-256 記於 [來源清單](../evidence/source-manifest.json)。未修改原件，未將其匯出日期當作課程日期。

公開庫收錄重新撰寫的分析、證據索引及第 14、25、29 頁節選。原稿的檢測報告示例、QR code、完整企業產品圖片及全部投影片未整包上傳。沒有提取個人健康數值作為資料集，也沒有解碼 QR code。

新增文字不替原稿的醫療措辭背書。例如，需求想像、行銷敘述與圖示不能證實存活時間預測、用藥效能、老化指標效度或疾病預防效果。這些產品評估未在本案進行。

## 尚未取得的證據

- 企業新增訪談、內部 SOP、程式或資料庫檢視。
- 產品測試方法、分析效度、臨床效度或臨床效益評估。
- 客戶理解、Kano／IPA 原始調查、營收與成本明細。
- 市場規模、市占率、競品同規格比較與長期留存紀錄。
- 台灣個案產品的法規認定、許可或法律意見。

FDA 與 NSGC 資料只作一般概念背景。美國的制度與專業建議不能直接代替台灣的適用規範，也不能據此判定公司合規或不合規。

## 檔案驗證方法

公開檔案的 SHA-256 列於 `evidence/SHA256SUMS`，排除清單本身與 `.git/`。可在專案根目錄執行：

```bash
shasum -a 256 -c evidence/SHA256SUMS
```

發布時另核對遠端 Git tree 與本機 Git blob。這些檢查確認檔案完整性與發布內容一致，不驗證商業假說、醫療效果或來源主張的真實性。
